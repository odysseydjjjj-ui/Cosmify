# Cosmify

Cosmify is a .NET MAUI local music-player project for Android and Windows.

## Project archive

The source project and PowerShell build scripts are kept in one archive:
[`Cosmify-project-with-build-script.zip`](./Cosmify-project-with-build-script.zip)

The archive contains the MAUI app, solution, resources, and scripts for restoring, cleaning, and building Android/Windows.

## Automated builds

GitHub Actions builds the Android APK and Windows app when the project archive or build workflow changes.

Open **Actions → Build Cosmify installers** to see the latest run. Successful builds are uploaded as the `Cosmify-installers` artifact (available for 14 days).

## Current scope

This repository contains an initial project scaffold. It is not a claim that every planned feature is implemented. Build output must be checked in Actions before treating installers as ready.
